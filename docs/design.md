## 1. 게임 개요

### 1.1 한 런 = 한 환자의 입원 경과

응급실(1막, 8층) → 병동(2막, 10층) → 중환자실(3막, 10층). 각 막 끝에 주 진단(1막 DKA, 2막 관문 상부위장관 출혈, 3막 패혈성 쇼크). 활력 70으로 시작하고 0이면 사망.

### 1.2 전투의 흐름: 안정화 → 감별 → 결정 → 치료 → 재평가

한 전투는 "문제" 하나(드물게 둘)다. 문제는 **주호소**로 시작하고, 실제 질병은 그 주호소의 감별 대상 중에서 숨겨 뽑는다.

| 단계 | 플레이어가 하는 일 | 쓰는 것 |
|---|---|---|
| 안정화 | 이번 턴의 임상 압박(의도)을 안정화로 막는다 | 안정화 조치, 신체 진찰(안정화 3), 산소, 수액 |
| 감별 | 무엇을 볼지 **고른다**. 소견이 가설을 지지·반대한다 | 병력·진찰·혈액·영상·현장 검사·배양·협진 |
| 결정 | 감별 목록에서 **작업 진단**을 정한다 (틀리면 바꿀 수 있다) | 감별 기록지 클릭 |
| 치료 | 처방집에서 약·시술을 불러 쓴다. 킥커·시술 결정 | 투약 오더, 시술 의뢰, 협진 |
| 재평가 | 치료 반응이 새 소견이 된다. 무반응이면 진단을 다시 본다 | 재평가, 투약 검토, 범위 축소 |

### 1.3 세 축

모든 카드와 결정은 세 축 중 하나 이상을 움직인다.

- **안정성**: 활력과 안정화. 지금 버틸 수 있는가
- **불확실성**: 감별 목록. 무엇인지 얼마나 아는가
- **부담**: 질병 부담(적의 체력), 부작용 카드, 내성, 오더. 치료의 대가

### 1.4 카드 두 곳

- **행동 덱(처방 목록)**: 의사가 "하는 일" 18종 + 시작 카드. 진단, 안정화, 순환, 호출(투약 오더·시술 의뢰·협진). 덱에 섞여 뽑힌다.
- **처방집**: 약 30종과 결정적 시술 9종. 덱에 섞이지 않는다. 투약 오더·시술 의뢰로 셋 중 하나를 골라 손으로 불러낸다(이번 턴 비용 0, 이번 전투 한정 임시 카드).

약이 덱에서 사라졌으므로 "이 환자에게 쓸모없는 약을 뽑는" 죽은 드로우가 구조적으로 줄었다. 그래도 손에 맞지 않는 치료 카드가 있으면 **반납**한다(§2.6).

## 2. 핵심 체계

### 2.1 소견과 감별 목록 (`src/core/evidence.ts`)

**경로(channel)** 27개: 활력징후, 병력 3(발병·동반·위험 인자), 진찰 4(심폐·복부·신경·피부/사지), 혈액 3(혈구·화학·응고), 현장 4(소변·심전도·동맥혈 가스·대변), 영상 3(X선·현장 초음파·CT), 배양 4(혈액·소변·객담·상처), 그람 염색 4(배양 경로에서 파생), **경과 관찰 1**(v2.1, 검사로 고르지 않는다 — §2.7). 소견은 `src/content/evidence.ts`에 문장과 가중치(0 정상 / 1 흔함 / 2 특징 / 4 거의 특이)로 있다.

**가중치 상한 (v2.1)**: 병력 ≤1(암시), 활력·진찰·혈액·현장 검사·X선·현장 초음파 ≤2, **가중치 4는 CT와 배양 결과에만**(비싸거나 시간이 걸린다), 경과 소견 ≤2. `validateContent`가 검사한다. 값싼 검사 하나로 감별이 끝나지 않게 한다.

질병은 경로마다 기대 소견을 가진다(`DiseaseDef.findings`, 변이·단계가 덮어쓸 수 있다). 기대 소견 집합은 모든 변이·단계의 합집합이다. 적지 않은 경로는 그 경로의 정상 소견이다. 경과 경로의 기대 집합은 그 질병의 행동·단계가 남길 수 있는 경과 소견 전부와 "특별한 경과 변화 없음"이다.

**비교 규칙** (가설 h, 관찰 소견 o, h의 기대 집합 E):
- o ∈ E: 지지 + weight(o)
- o ∉ E이고 o가 이상 소견: 반대 + weight(o) — 관찰한 소견이 얼마나 특이한가
- o ∉ E이고 o가 정상 소견(기대한 특징 소견이 없음): 반대 + 1

**신뢰도** (score = 지지 − 반대):
- 반대 ≥ 5 → **배제**
- 남은 가설이 하나 → 강력 의심
- score ≤ −2 → 가능성 낮음
- score ≥ 5이고 다음 가설보다 3 이상 앞섬 → 강력 의심
- score ≥ 2 → 의심
- 그 밖 → 가능

v2.0은 반대가 max(기대, 관찰)이고 배제 4·강력 의심 4였다. 가중치를 묶은 뒤에도 반대 소견 둘로 셋 중 둘이 첫 턴에 배제되어 다시 맞췄다(DECISIONS v2.1-2).

**확진**: 배제되지 않은 가설이 하나이고 score ≥ 2. 확진되면 질병명·변이·단계·특성 문구와 의도의 정확한 수치가 보이고, 병례집에 기록되고, 작업 진단이 없으면 자동으로 정해진다. 이 계산은 관찰(플레이어 정보)만 쓴다.

**정답은 배제되지 않는다**: 실제 질병의 소견은 늘 그 질병의 기대 집합 안에 있다(비전형 소견 제외). `tests/scenario/diagnosis.test.ts`가 모든 내원 양상·후보·변이·비전형 조합(약한 둘째 비전형 포함)에서 전 경로를 관찰해 확인한다.

**비전형 소견** (`DiseaseDef.atypical`): 감별 대상이 둘 이상인 문제는 60% 확률로 한 경로가 비전형 소견을 낸다. 같은 내원 양상의 다른 후보가 기대하는 소견(흉내, 예: 심부전의 천명음)을 세 배로 고른다. 그중 30%는 약한(가중치 ≤1) 비전형이 하나 더 있다. 비전형의 반대 근거 합은 3 이하라 배제(5)에 닿지 않는다(검증기가 강제).

**활력징후**: 감별 대상이 둘 이상인 내원 양상은 공통 활력 징후(`PresentationDef.vitals`)로 온다. 전투 시작 때 보이고 채점하지 않는다(`Observation.neutral`). v2.0은 질병마다 달라 첫 화면이 답을 흘렸다.

**감별 가능성 검사**: 같은 내원 양상의 두 후보는 활력징후 밖의 어떤 경로에서 기대 집합이 겹치지 않아야 한다(`validateContent`).

### 2.2 작업 진단 (`commit_diagnosis`)

- 감별 목록에서 배제되지 않은 가설을 눌러 정한다. 처음은 무료, 바꾸면 **오더 1**.
- 효과: 그 진단의 1차 치료(교과서 반응이 모두 "좋음")에 **치료 계획 배율 ×1.3**(교수 회진은 +30%p). 항생제는 배양으로 원인균을 확인했을 때 그 균 기준으로 1차인지 본다. 투약 오더가 작업 진단 기준으로 약을 고르고, 작업 진단에 금기인 약은 내놓지 않는다.
- 틀린 작업 진단의 대가: 계획 배율이 붙지 않고, 그 진단에 맞춘 약은 실제 질병에 듣지 않거나 해롭다. 무반응은 반응 소견으로 기록되고 작업 진단 가설을 깎는다(§2.3). 경과 기록이 "작업 진단 X이라면 들었어야 한다. 진단을 재고하라"라고 알린다.
- 봇 기준 첫 작업 진단 정확도·결정 시점·변경 횟수는 텔레메트리로 잰다.

### 2.3 치료 반응은 소견이다

치료 카드가 문제에 닿으면 반응이 `rx:<카드>` 경로의 소견으로 남는다: 뚜렷한 호전(2)·부분 반응(1)·반응 없음(0)·악화(4). 가설마다 그 약의 교과서 반응 분류와 비교한다. 예: 아나필락시스에 에피네프린이 극적으로 들으면 천식 가설이 내려간다. 항생제 반응은 원인균 후보도 거른다.

### 2.4 배양, 원인균, 내성, 미생물 기록 (`src/core/micro.ts`)

- 배양 검사(또는 감염내과 협진)에서 **검체를 고른다**: 혈액·소변·객담·상처/삽입부.
- 그람 염색은 즉시(그람 양성 알균, 그람 음성 막대균, 없음), 배양·감수성은 **2턴 뒤**(강화하면 1턴). 재평가의 "대기 결과 확인"으로 1턴 앞당긴다.
- 원인균이 확인되면 감별 기록지에 감수성표가 뜨고, 투약 오더는 그 균의 감수성으로 항생제를 고른다(관찰한 배양 소견에서 읽는다). 감염내과 "감수성에 맞춘 항생제"로 가장 좁은 유효 항생제를 받을 수 있다.
- **미생물 기록 (v2.1, 런 단위)**: 전투가 끝날 때 배양 중인 검체(문제가 나은 경우 포함)는 계속 자라고, **다음 전투가 시작될 때** "미생물 검사실 회신"으로 도착한다. 전투 중에 나온 결과와 함께 원인균·감수성표가 런 끝까지 환자 차트(배너의 "미생물" 단추)에 남는다. 차트에 있는 균은 이후 문제의 원인균 후보 도움말에 "환자 차트의 앞선 배양"으로 보인다.
- **선택 압력 (v2.1, 화면에 보인다)**: 광범위 항생제 +2, 원인균을 모르고 쓴 좁은 항생제 +1(한 전투에 약마다 한 번), 원인균을 확인한 뒤 범위 축소 −2. 이후 감염의 변이를 뽑을 때 내성균(ESBL·MRSA·녹농균) 변이 가중치를 1당 +10%(최대 +150%), 차트에 같은 균이 있으면(집락) +100%. 인카운터 난수로 결정적으로 뽑고, 변이 자체는 숨은 정답이다. 연결은 모두 unverified(`MICRO_MEDICAL`).
- **내성 규칙**: 원인균을 모른 채 쓴 항생제, 또는 광범위 항생제는 질병의 획득 내성을 쌓는다(질병별 `acquiredResistance`). 확인한 뒤의 좁은 항생제는 쌓지 않는다. 획득 내성은 원인균의 성질이라 **원인균 확인이나 확진 전에는 화면·미리보기에 보이지 않는다**(v2.1: VAP의 시작 내성이 첫 화면에 보였다).
- **범위 축소**: 투약 검토·재평가의 "투약 검토"·감염내과 권고에서 광범위 항생제를 끊는다. 원인균을 알면 장내세균 교란 정리, 카드 1장, **오더 +1, 선택 압력 −2**.

### 2.5 임상 결정 (`choose_option`, `src/core/choice.ts`)

카드 하나가 2–4개 선택지를 내놓는 범용 결정 체계다. 선택지(`OptionDef`)는 이름, 짧은 이득(`detail`), 위험(`risk`), 추가 오더(`cost`, 킥커), 조건(`requires` + 플레이어용 문구 `requiresText`), 효과 목록을 가진다.

- **고를 수 없는 선택지는 이유를 보여 준다**: "이미 확인한 소견", "결과 대기 중", 조건 문구, "오더 부족 (+N 필요)".
- **경로 선택지**에는 플레이어 정보로 만든 힌트가 붙는다: "특징 소견이 예상되는 가설: 천식·폐렴" 또는 "감별 중인 가설 모두 정상 소견이 예상된다".
- **여러 개 고르기**(`picks`): 강화한 병력 청취·신체 진찰·혈액 검사는 둘을 고른다. 두 번째부터는 고른 것을 뺀 선택지로 다시 열리고 건너뛸 수 있다.
- **중첩**: 선택지 효과 안에 다시 `choose_option`을 둘 수 있다(협진 → 진료과 → 권고 → 배양 검체).
- **선택지 생성**: `discover`(처방집), `consult`(진료과), `procedure_decision`(시술), `stop_drug_choice`(투여 중 약)는 상황에 맞춰 선택지를 만든다.
- 결정 중에는 다른 행동(카드, 턴 종료, 작업 진단, 반납)이 막힌다. 대기 결정은 상태에 직렬화되어 저장·복원·재생이 결정적이다.
- 가짜 결정을 만들지 않는다: 처방집에서 쓸 만한 것이 하나뿐이면 "처방하지 않음"(오더 1 반환, 1장 뽑기)을 붙인다. 선택지가 모두 막히면 결정을 열지 않는다.

### 2.6 처방집 호출, 협진, 시술, 반납

**투약 오더 / 시술 의뢰 (`discover`)**: 처방집의 약(또는 시술)에서 셋을 골라 보여 준다.
- 작업 진단이 있으면 **표적**, 역할로 고른다(v2.1): **1차**(가장 잘 듣는 것) · **대안**(한 등급 아래까지 들으면서 부작용·광범위의 대가가 적은 것) 또는 **차선**(다른 약) · **보험**(작업 진단이 틀렸을 때 다른 가설에 듣는 것), 남는 칸은 **보존적**(안정화). 선택지마다 무엇을 맞바꾸는지 앞에 적는다. 원인균을 배양으로 확인했으면 항생제는 그 균의 감수성으로 값을 매긴다.
- 없으면 **경험적**: 감별 목록의 가설들을 신뢰도 가중치로 넓게 덮는 순서(탐욕적 덮기).
- 부작용·환자 상태를 정리하는 관리 약이 필요하면 한 칸을 준다.
- 문구는 가설별 교과서 반응("폐렴 무효~우수")과 금기·부작용을 적는다. 정답을 쓰지 않는다.

**협진 (`consult`)**: 진료과 셋을 감별 목록과 맞는 순서(특성 일치 2점, 분류 일치 1점, 신뢰도 가중)로 보여 준다. 진료과는 권고 셋 중 하나를 따른다. 권고는 소견(CT, 심초음파), 전문 도구(내시경, 혈전용해, 투석, 삽관), 항생제 전략(배양 먼저, 경험적 광범위, 감수성에 맞춘 항생제)이다. 전문 도구는 내 처방집에 없어도 되지만 **비용은 그대로** 낸다. 협진 카드는 소진.

**결정적 시술** (`CardDef.procedure`): 쓰면 결정이 열린다.
- **즉시 시행**: 위험은 플레이어가 아는 근거로 정한다. 이 시술이 듣는 가설이 강력 의심이면 낮음, 의심이면 활력 −2, 그보다 약하면 활력 −5와 시술 합병증 카드.
- **확인 후 시행**(오더 +1): 확인 검사 소견을 먼저 얻고 시행·보류를 고른다.
- **보존적 치료 유지**: 안정화 4, 카드는 손으로 돌아온다.
결정적 치료가 맞으면 질병의 기전이 바뀐다(`DiseaseDef.definitive`: 합병증 예고 취소, 활동성 출혈 정지 등, 한 번).

**처방 반납 (`return_card`)**: 손의 치료 카드(약·치료 시술) 하나를 약제부로 돌려보낸다. 턴당 1회(가이드라인으로 +1), 오더 없음, 카드 1장 뽑기. 임시 카드는 폐기, 덱 카드는 대기 처방 맨 아래. 치료가 아니므로 반응 소견이 남지 않는다.

**킥커 강화**: 수액(신중/표준/적극적 소생), 인슐린(표준/집중), 에피네프린(근육/정맥 지속), 노르에피네프린(저용량/빠른 증량)은 오더를 더 내면 세지고 대가(체액 과다, 저혈당, 부정맥)를 손에 넣는다.

### 2.7 임상 압박 (의도)과 경과 소견

**보이는 의도 = 압박 종류 + 크기 등급.** 확진 전에는 압박 종류(혈압·순환 악화, 호흡 악화, 출혈 진행, 의식·신경 악화, 대사 악화, 염증 진행, 심장 부담·부정맥 위험, 신기능 악화, 통증·불안정, 병세 진행, 합병증 예고)와 크기 등급(**경미 ≤6 · 중등 7–12 · 심각 ≥13**, 행동에 적힌 환자 피해 합으로 고정)만 보인다. 정확한 수치·효과·행동 이름은 일어난 뒤에(또는 확진 뒤에) 보인다. 예상치는 등급 대표값(4·10·16)에 플레이어가 보는 보정(질병의 악화·산증, 환자의 취약, 질병의 약화, 인카운터 공격 배율)만 더해 다시 등급을 매긴다.

**경과 대본 (`PresentationDef.course`).** 감별 대상이 둘 이상인 내원 양상은 의도의 칸("종류:등급", 합병증 예고는 "complication:등급@턴")을 내원 양상이 적 난수로 고른다(시작 칸, 가중치, 연속 금지, 턴·예고 유무 조건의 규칙). 실제 질병은 그 칸의 자기 행동을 낸다(같은 칸이 여럿이면 덜 쓴 것부터, 난수 없이). 그래서 보이는 의도의 순서가 정답과 무관하다. 모든 후보는 대본의 모든 칸에 행동이 있어야 한다(`validateContent`). 타격 수 난수는 적 난수를 쓰지 않는다(소모량이 정답에 따라 갈라지지 않게). 자기 행동표를 가진 단계(예: 심근경색의 심실세동)에 들어가면 질병 AI로 돌아가는데, 그 단계는 반드시 경과 소견을 남긴다. 감별 대상이 하나인 관문·보스는 질병 AI를 쓴다.

**경과 소견.** 질병 고유의 악화는 일어난 뒤 경과 경로의 소견으로 남는다(`MoveDef.course`·`PhaseDef.course`, 가중치 ≤2). 예: 아나필락시스 기도 부종 → "입술과 혀가 눈에 띄게 부어오름", 충수염 천공 위험 → "통증이 오른쪽 아랫배로 모이고 반발통이 생김", 심근경색 심실세동 → "모니터에 심실세동이 나타남", 뇌내출혈 혈종 확장 → "의식이 한 단계 더 떨어짐". 채점·설명은 다른 소견과 같다. 한 후보만의 예고는 다른 후보에 같은 칸의 예고를 주거나(다리 부종: 혈전 이동 위험 / 고름집 형성 위험, 폐쇄성 쇼크: 무맥성 전기활동 / 심정지, 두근거림: 좌심방 혈전 / 색전 재발, 심한 윗배 통증: 췌장 괴사 / 심실 부정맥) 경과 소견으로 드러낸다.

`npm run intent:leak`이 내원 양상마다 칸 집합·첫 의도·후보별 충족·8턴 의도 순서(시드 20개, 경과 소견 전까지)를 비교한다.

### 2.8 피해 파이프라인 (v1.1 §4.4에서 바뀐 곳)

배율 목록은 `[등급 e, 계획 p, 내성 r, 현재 카드 s, 취약 v, 위축 w, 유물·조건부 m…]`이다. v1.1의 표적 배율 `t`(확진 ×1.5)는 없어졌고, **계획 배율 p**(작업 진단의 1차 치료 130 + 교수 회진 보너스)가 그 자리에 있다. 확진은 피해를 바꾸지 않는다. 항생제 고정 가산(항생제 관리 프로그램 +3)은 원인균을 확인했을 때만 붙는다. 금기·전신 금기·안정화 흡수는 v1.1과 같고, 금기 반응은 "악화" 반응 소견을 남긴다.

**미리보기**: 확진 전에는 가설별 교과서 반응과 예상 수치를 보여 준다. 범용 카드인지도 감별 목록으로 판단한다(숨은 질병의 판정을 쓰지 않는다).

### 2.9 보상과 성장

**카드 보상 3칸** (`generateCardChoices`):
- **일반**: 행동 덱 카드(진단·안정화·순환 등)
- **상황**: 처방집 추가. 이번 막(막 후반이면 다음 막까지) 환자에게 듣는 것만, 쓸모에 비례해 뽑는다. 쓸모 = Σ 질병을 만날 기대 횟수(풀별 전투 수 × 인카운터 비율 × 감별 대상 비율) × 교과서 반응(특효 3·우수 2·보통 1)의 **이미 가진 처방집보다 나아지는 만큼**(같거나 못하면 1/4). 막이 진행될수록 다음 막에 비중을 준다(v2.1). 이미 있는 것은 제외
- **특수**: 빌드를 정하는 고급·희귀 행동 카드 또는 희귀 처방집

약·시술을 고르면 처방집으로, 이미 있으면 최적화(강화)된다. 관문·보스 보상에는 **다음 병동 처방집 신청**(다음 막 환자에게 듣는 것 3개 중 1개)이 붙는다. 약제부는 일반 2·상황 2·특수 1 칸을 판다. 당직실 최적화는 덱과 처방집 모두에서 고른다.

**퇴원 요약**: 전투가 끝나면 보상 화면이 실제 진단(변이 포함)과 작업 진단이 맞았는지 보여 준다. 틀린 진단은 여기서 배운다.

**빌드 정체성**: 진단 빌드(현장 검사·배양·교수 회진·감별진단 체크리스트), 안정화 빌드(집중 모니터링·중심정맥관·수액 프로토콜), 항생제 관리 빌드(배양·항생제 관리 프로그램·범위 축소), 순환 빌드(차트 정리·인계·신속대응팀), 시술 빌드(시술 의뢰·결정적 시술).

### 2.10 유물(가이드라인)에서 바뀐 것

- 인턴 수첩(시작): 전투가 시작될 때 대기 처방에서 진단 카드 1장을 손으로 가져온다(무엇을 볼지는 여전히 플레이어가 고른다)
- 진료 지침 요약본: 처음 작업 진단을 정할 때와 확진할 때 카드 1장
- 항생제 관리 프로그램: 획득 내성 절반, 원인균을 확인한 문제에 항생제 +3
- 패혈증 1시간 번들: 첫 턴에 처음 쓰는 배양 검사와 항생제 비용 0
- 감별진단 체크리스트: 매 턴 처음 여는 진단 카드 결정에서 하나 더 고른다
- DUR 시스템: 첫 위험 상호작용 차단에 더해 반납을 턴마다 한 번 더

### 3.4 결정론

모든 선택지 생성은 상태와 난수 스트림만 쓴다. 결정 중 저장·복원 후 같은 선택은 같은 해시를 낸다(`tests/determinism`, `tests/scenario/decisions.test.ts`). 판단 봇 전체 런도 행동 기록 재생으로 같은 해시.

### 3.5 봇과 텔레메트리 (`src/sim`)

- **ClinicianBot**: 플레이어 정보만 쓴다. 감별 목록의 신뢰도를 믿음으로 보고, 경로 감별력으로 검사를 고르고, 첫 턴에는 강력 의심일 때만, 둘째 턴부터(또는 위협이 활력의 35% 이상이면) 앞선 가설로 작업 진단을 정하고, 가설별 미리보기로 치료 가치를 잰다. 감염이 의심되면 배양을 먼저 하고, 감수성표를 따르고, 원인균을 알면 범위 축소를 한다. 쓸모없는 치료 카드는 반납한다. `{ blind: true }`는 검사를 하지 않고 경험적 치료만 하는 비교용 봇이다.
- **RandomBot**: 합법 행동 중 무작위. 퍼즈 테스트용.
- `npm run sim -- blind --n 20`: 같은 시드로 검사하는 봇과 검사하지 않는 봇을 짝지어 활력 손실을 비교한다(검사가 나은 짝·나쁜 짝 비율).
- `npm run sim -- metrics --n 200`이 출력하는 지표(v2.1 추가: 막별 사망 원인, 검사 하나로 강력 의심에 이른 문제, 작업 진단이 바뀐 전투, 확진 포함 첫 작업 진단, 3막 감염 전투 표적 항생제, 범위 축소가 있던 런, 다음 전투에서 도착한 배양 결과, 런 끝 선택 압력, 작업 진단이 있을 때 투약 오더 선택 위치): 승률, 도달 막, 사망 원인, 막·종류별 전투당 활력 손실과 턴, 손패 중 쓸 수 없는 카드 비율, 치료 카드 드로우 중 적응증 없는 비율(죽은 드로우), 보상 화면당 의미 있는 선택지 수, 얻고 쓰지 않은 덱 카드·처방집 비율, 전투당 결정 수, 결정당 고를 수 있는 선택지 수, 턴당 그럴듯한 행동 수, 전투당 소견 수, 첫 작업 진단 정확도·시점, 전투 끝 작업 진단 정확도, 작업 진단 변경, 경험적/표적 항생제, 범위 축소, 반납, 무반응 소견, 선택지 분포.

### 5.6 질병

질병 28종의 치료 반응표, 변이, 단계, 행동은 `src/content/diseases/act1–3.ts`에 있고 `npm run content:report`가 목록을 출력한다. v1.1 §5.5의 질병 설명(의학적 근거)은 그대로 유효하다. v2.0에서 질병마다 더한 것:

- `textbook.keyFeatures`: 교과서 한 줄(감별 기록지 툴팁, 병례집)
- `findings`: 경로별 기대 소견(변이·단계가 덮어씀). 예: 폐렴알균 폐렴 = 한쪽 수포음·X선 엽 경화·객담 그람 양성 알균, 비정형균 = 흩어진 수포음·X선 반점 음영·배양 음성
- `atypical`: 비전형 소견(최대 2 감점)
- `definitive`: 결정적 치료가 바꾸는 기전(예: 내시경 지혈 → 재출혈 예고 취소·활동성 출혈 정지, 재관류 → 허혈 진행과 합병증 예고 취소)
- 행동의 `pressure`(임상 압박 종류)
- 뇌경색: CT로 출혈을 확인하지 않고 혈전용해제를 쓰면 출혈 카드와 활력 −6. 신경과 협진의 혈전용해 권고는 이 위험을 문구로 알린다
- 상부위장관 출혈: `active_bleeding`(턴마다 활력 −1) — 내시경 지혈로 멈춘다

v2.1에서 더한 것:

- **뇌내출혈 `ich`(신규, unverified)**: 뇌경색의 감별 대상. 두통·구토·처지는 의식, 와파린, INR 연장, CT 혈종. 혈전용해·항응고·항혈소판 금기, 혈압 조절(β차단제로 통합) 우수·수혈(항응고 역전으로 통합) 보통. 뇌경색의 골든타임과 같은 3턴 예고(혈종 확장, 혈압 조절이 들으면 취소)
- 대본의 칸을 채우는 행동과 경과 소견(§2.7), 흉내 비전형 소견(§2.1), DIC의 활동성 출혈(출혈 내원 양상에서 상부위장관 출혈과 같은 모습), 봉와직염의 고름집 형성 예고(항생제가 들으면 취소), 폐색전증의 색전 재발 예고·심근경색의 심실 부정맥 예고, 아나필락시스 기도 부종 예고 제거(에피네프린의 결정적 효과는 악화 해제 + 질병 부담 8)
- 모든 질병의 `medical`은 unverified(v2.0에서 소견·감별이 붙었고 소유자가 아직 보지 않았다). 이전 표시는 메모에 남겼다

## 6. 테스트

| 묶음 | 내용 |
|---|---|
| `tests/unit` | 피해 파이프라인(등급, 계획 배율, 금기 반응 소견), 합법 행동, 지도, 난수 |
| `tests/scenario/diagnosis` | 소견과 신뢰도, 음성 소견, 확진, **정답 불배제 속성**, 작업 진단·변경 비용, 치료 반응 소견, 배양 타이밍, 내성 규칙, 결정 중 행동 차단 |
| `tests/scenario/decisions` | 선택지·이유·킥커·여러 개 고르기·중첩·합법 행동·결정 중 저장/복원, 처방집 호출(표적·금기 제외·처방하지 않음·정답 무관), 시술 결정, 반납 |
| `tests/scenario/integrity` | 감별 대상이 둘 이상인 모든 인카운터에서 정답을 정해 시작한 전투들의 화면 정보(**의도 포함**)·미리보기·합법 행동·투약 오더·협진 선택지가 같다. 6턴 동안 질병이 행동해도 결과가 갈라지기 전까지 화면이 같고, 대본이 고른 칸은 끝까지 같다. 같은 화면이면 판단 봇이 같은 행동을 고른다. 변이 무관, 차트의 균은 후보로만, 기록에 질병명 없음 |
| `tests/scenario/micro` | 배양이 다음 전투에서 도착하고 차트에 남음, 선택 압력(광범위·경험적·범위 축소), 내성균 변이 가중치, 범위 축소의 오더 반환 |
| `tests/scenario/rewards` | 보상 3칸, 처방집 경로, 중복 최적화, 다음 막 처방집 신청, 퇴원 요약 |
| `tests/scenario/drugs` | 반감기, 부작용 시점, 상호작용, 킥커 대가, 전신 금기 |
| `tests/content` | 검증 오류 0, 개수, 단순 카드 비율, 설명문 |
| `tests/determinism` | 리플레이 해시(무작위 봇 20판, 판단 봇 3판), 결정 중 저장·복원 |
| `tests/fuzz` | 무작위 봇 전체 런(기본 40판, `test:fuzz` 200판)·판단 봇 6판의 불변식(정답이 감별 목록에 있음, 작업 진단이 감별 목록에 있음, 죽은 대기 결정 없음 등) |

브라우저: `scripts/ui-smoke.ts`가 실제 클릭으로 결정 창과 작업 진단을 거쳐 한 판을 진행한다. `scripts/screenshots.ts`는 판단 봇으로 만든 상태를 주입해 모든 화면을 찍는다.

## 7. 명령

```
npm run dev                      # 개발 서버
npm test                         # 전체 테스트
npm run test:fuzz                # 긴 퍼즈
npm run typecheck
npm run build                    # 웹 빌드 (dist/)
npm run build:artifact           # 단일 HTML (dist-artifact/order-set.html)
npm run content:report           # 콘텐츠 검증과 의학 데이터 목록
npm run medical:review           # 소유자 의학 검토 문서 (docs/medical-review.md)
npm run intent:leak              # 내원 양상별 의도 누설 검사
npm run sim -- blind --n 20      # 검사하는 봇 대 경험적 치료만 하는 봇
npm run sim -- combat --deck act1 --act 1 --n 40 [--encounter id] [--formulary act1|목록]
npm run sim -- metrics --n 200   # 전체 런 텔레메트리
npm run replay -- run.json       # 행동 기록 재생 검증
npm run shots                    # 화면별 스크린숏 (개발 서버 필요)
```
