## 화면 확인

`npm run shots`로 화면별 스크린숏을 `shots/`에 만든다(커밋하지 않음). 확인하며 고친 것: 좁은 화면에서 무대가 옆으로 밀리던 문제, 오버레이가 무대 일부만 덮던 문제, 세로쓰기 탭 글자가 뒤집히던 문제, 괘선이 글자를 가르던 문제, 종결 도장이 처방 목록을 가리던 문제, 가이드라인 배지가 넘치던 문제, 지도 오른쪽 끝이 잘리던 문제, 초점 이동이 무대를 스크롤시키던 문제.
